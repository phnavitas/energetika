# Navitherm arculat

- **Jel:** dőlt N – két fekete (sötét alapon fehér) szár, köztük jelzősárga hősáv (#FFC800 → #FFE45C).
- **Felirat:** „navitherm”, Chakra Petch Bold, görbékké alakítva (a fájlok betűtípus nélkül is pontosak).
- **Színek:** fekete #111111, jelzősárga #FFC800, világos sárga #FFE45C, fehér.
- **Forrás:** `apps/web/src/arculat.tsx` – a programban (fejléc, belépés, böngészőikon, PDF-jegyzőkönyv) innen jön minden.
